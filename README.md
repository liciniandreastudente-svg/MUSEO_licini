Licini Andrea 4^ID
Museo virutale realizzato con europeana e hugging face

Questa è un applicazione web moderna e reattiva che permette di esplorare milioni di opere d'arte provenienti dai musei di tutta Europa, integrando un assistente virtuale basato su Intelligenza Artificiale per l'analisi dettagliata dei capolavori.

L'applicazione permette agli utenti di:
 -Ricercare milioni di opere presenti sul suolo europeo.
 -Chiedere una descrizione approfondita delle opere a un assistente AI.

 Framework:
  -Vue.js 3: Framework JavaScript scelto per la gestione reattiva dell'interfaccia.
  -Vuetify 3: Framework UI personalizzato usando un tema scuro con dettagli in oro per richiamare l'estetica elegante e raffinata dei musei europei.
 API:
  -API Europeana: API utilizzata per ricevere le opere d'arte. È il database digitale ufficiale dell'Unione Europea per il patrimonio    culturale, interrogato con parametri specifici per filtrare esclusivamente contenuti multimediali di tipo immagine.
  -API Hugging Face: endpoint di Hugging Face sfruttato per interrogare il modello Llama 3 e ricevere informazioni dettagliate sulle opere.
